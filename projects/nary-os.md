## Présentation

Le système que tu es en train de parcourir : un **bureau complet simulé dans le README de profil GitHub**. Wallpaper Phoenix, barre système, icônes d'applications, dock et séquence de démarrage, le tout en Markdown, HTML autorisé par GitHub et images pré-rendues. Aucun JavaScript, aucun CSS externe, aucun serveur.

## Principes

- Chaque icône est une image indépendante liée à une page Markdown.
- Navigation par liens relatifs : Back, Home et un header commun à chaque page.
- Boot en GIF pré-rendu, terminant sur l'écran de verrouillage.
- Assets générés en SVG, exportés en PNG optimisés ; scripts de régénération dans `image/src/`.
- Compatible mobile (grille d'icônes limitée à 4 colonnes).
